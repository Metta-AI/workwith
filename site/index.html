Reply to Claude Code the way you mark up a draft.

Codiner is a web UI over Claude Code. Select any passage of Claude's answer and comment on it in the margin. Answer its questions where it asks them. Send everything in one go. Run many sessions side by side, each with a small critter that shows what it is doing.

Install Source on GitHub Free and open source. Runs on your own Claude Code login.

Reply in the margin

A chat box makes you quote by hand. Codiner lets you select a passage of Claude's answer and type your note beside it, the way you review a draft. Each note goes to Claude as the quoted passage with your words under it:

> I left the annual plan out, because the checkout cannot take it yet.

Fine for today. Put it behind a flag so we can turn it on next week.

> Sales changed the Team price in August.

💪
Comments

Select, then type

A comment card opens in the right margin, level with the passage. Cards stack so they never overlap. Sent comments stay as read-only cards.

Reactions

An emoji on any paragraph

Move the pointer to a paragraph and click the faint emoji at its left. Press and hold for your most used ones. A reaction on an item counts as a reply to it.

One send

Nothing slips past

A panel lists the open questions and items. If you send while some are still open, Codiner tells you first. Claude gets one line for the items you set aside.

Five kinds of content

Codiner tells Claude to mark each part of its reply. Each kind looks different, so you can see at a glance what needs you.

AnswerThe direct answer, first, marked in the accent colour.
DetailsSupporting detail, folded to its title until you open it.
ConsiderA problem, risk or trade-off, as an amber card with Reply and Dismiss. Tasks for you get a Done button.
AskA question in place, with suggested answers to click and a box for your own.
RunA command you must run yourself, with Run in Terminal and Copy. The exit code and output go back to Claude.

Many sessions, one critter each

Run sessions side by side, grouped by folder. Each Claude dresses its own critter, so you can tell them apart. The pose shows the status. The face shows how full the context is: the eyes droop, it sweats, then it falls asleep.

Master agent

One Claude to watch the rest

The Master view shows every session as a card, beside a chat with a separate Claude. It can read, message, start and compact the other sessions. Its messages land in an inbox for you to send, unless you turn on Auto-send.

History

Pick up any conversation

Resume… lists every Claude Code conversation on your machine, including the ones you started in a terminal. Edit or delete a sent message, and Claude forgets everything after it.

Slash commands

Your skills, your commands

Type / for the commands of the session, with descriptions. A message that is only a slash command runs as if you typed it at the claude prompt.

It runs on your Claude Code login

Each session is a real claude process, driven with the same headless protocol as the Agent SDK. It uses your subscription, your settings, your CLAUDE.md, your skills and your MCP servers. Codiner removes API keys from the environment of the process, so it cannot bill per token by accident. The sidebar shows your 5-hour and 7-day usage.

The server listens on 127.0.0.1 only and rejects requests from other origins. A web page you visit cannot reach it.

Install

You need Node 23.6 or later and the claude CLI, logged in.

git clone https://github.com/huttj/codiner
cd codiner
npm install
npm start          # then open http://localhost:4545

Use npm run dev to work on Codiner itself. The UI reloads as you edit.

Questions

Does it cost anything?

Codiner is free and MIT licensed. It uses your own Claude Code plan, the same as the terminal does.

Is my code sent anywhere new?

No. Codiner runs on your machine and talks only to the claude processes it starts. Claude Code talks to Anthropic as it always does.

Can I still use the terminal?

Yes. Claude Code keeps its own transcripts, so claude --resume picks up any Codiner session, and Codiner can open any terminal session.

Can I tell every session how to write?

Yes. ~/.codiner/AGENTS.md goes into the system prompt of every session. Edit it in Settings. By default it asks Claude to write in Simplified Technical English.

Does it work on Windows or Linux?

The server is plain Node, so it should. Run in Terminal and the native folder dialog are macOS only.
